# Разработка itrampoline

Следуйте [AGENTS.md](../AGENTS.md) и [IDLE.md](../IDLE.md).

## Исходники

Python-пакет находится в `src/itrampoline/`:

- `cli.py` — аргументы, вопросы и представление результата.
- `stock.py` — штатные платформы и пути SD.
- `build.py` — чтение ресурсов, сборка и проверка двух ARM ELF.
- `database.py` — проверка схемы и добавление пункта в SQLite.
- `filesystem.py` — файловые проверки и публикация.
- `install.py` — сеанс установки и его ресурсы, план, конфликты и PC-бэкап.

Тесты находятся непосредственно в `tests/`, без вложенного каталога `itrampoline`.
Rust workspace поставляется в `src/itrampoline/resources/runtime/`:
`common` содержит файловые примитивы, `core` — libretro ABI,
`helper` — очистку после exec. [Цепочка запуска и проверки](runtime.md).

## Проверки и упаковка

Из каталога пакета:

```bash
ma tools
ma tests
uv build
cd src/itrampoline/resources/runtime
cargo test --offline --locked --workspace
```

Python-проверки выполняются только на 3.12. Тесты используют синтетические
данные и не требуют SD, оборудования, сети или привилегий.
Линтеры и форматтеры запускаются только по прямой просьбе владельца.

Wheel содержит Python-пакет, необходимые Rust-исходники и Cargo.lock,
метаданные и лицензию; не содержит тесты или готовые ARM ELF.
Sdist также содержит тесты и документы. `uv.lock`, кеши, окружения, дампы
и временные результаты не включаются.

Установленная команда не зависит от соседних проектов и дампов.
Ресурсы читаются через `importlib.resources`. Временная сборка удаляется;
для неё можно направить стандартный `TMPDIR` в tmpfs.
Происхождение сборки сохраняется в исходниках пакета и Cargo.lock, не в SD-инвентаре.

## Зафиксированные результаты

11 октября 2026 года, Python 3.12.3 и Rust 1.99:

- 61 Python-тест прошёл: в том числе отказ до Cargo, подтверждение замены,
  отмена и освобождение корня и временной сборки.
- Пять Rust-тестов и отдельная post-exec/FD-exec фикстура прошли.
- Сборочный скрипт проверен отдельно: семь ошибочных и два успешных сценария;
  внешние ошибки возвращаются без panic.
- ARM helper — 505660 байт, core — 21068 байт; у core ровно 25 экспортов `retro_*`.
  Оба ELF без INTERP/NEEDED/TEXTREL и неразрешённых динамических символов.
- Проверены wheel/sdist и установленная wheel-команда из постороннего каталога:
  сборка ARM и установка на синтетическую SD в RAM.

Временные бинарники удалены. Rust 1.85 и CI не запускались.
Реальные SD/NOR, GPIO и питание не менялись; эти результаты не подтверждают
аппаратный запуск.
