# Использование itrampoline

## Подготовка

На ПК нужны Linux, Python 3.12+, `uv` и Rust 1.85+.

Из каталога исходников itrampoline:

```bash
rustup target add armv7-unknown-linux-musleabihf
uv tool install --force -e .
```

Каталог исходников оставьте на месте. Для первой сборки может понадобиться интернет.

iman и IGUI на SD устанавливаются через [iroll](https://github.com/idleboxed/iroll).
Это можно сделать до или после установки itrampoline; приложения нужны для запуска
пункта меню, а не для его добавления.

## Добавление пункта меню

Выключите стик, подключите SD к ПК и откройте карту. На ней должна быть исходная
база игр `game/games.db`. Не форматируйте карту и закройте программы, работающие с ней.

Запустите команду из папки на ПК, не с самой SD. Вместо `/path/to/mounted-sd`
укажите путь к карте:

```bash
itrampoline /path/to/mounted-sd
```

Программа покажет платформы и имена их ядер. Выберите номер или нажмите Enter,
чтобы оставить Daphne. Игры выбранной платформы перестанут запускаться через
штатное меню: вместо их ядра будет установлен трамплин.

Перед заменой существующего ядра или запускателя программа спросит разрешение.
Если позже выбрать другую платформу, прежнее ядро автоматически не восстановится.

`--no-ask` выбирает Daphne без вопросов, но останавливает установку, если нужна
такая замена. Повторная установка не добавляет второй пункт меню.

Когда itrampoline, iman и IGUI установлены, безопасно извлеките SD из ПК,
верните её в стик и выберите **iboxed trampoline**. iman запустит IGUI.

## Файлы на SD

Результат для Daphne:

| Путь от корня SD | Назначение |
|---|---|
| `retro_lib/daphne_libretro.so` | Трамплин вместо штатного ядра Daphne |
| `system/itrampoline` | Запускатель приложения |
| `game/iboxed trampoline.itr` | Текстовый файл с путём к iman |
| `game/games.db` | Исходная база игр с новым пунктом |

Трамплин запускает `system/iman/iman`, а iman — IGUI.
Если iman ещё нет, программа предупредит об этом, но добавит пункт меню.

## Запуск другой программы

В `game/iboxed trampoline.itr` замените `system/iman/iman` на путь к программе
от корня SD. Оставьте одну строку с переводом строки в конце, без аргументов,
начального `/` и `..`. Нужна программа для Linux на стике (ELF), не скрипт;
ссылки не поддерживаются.
Повторная установка сохраняет указанный путь.

## Резервные копии и отмена установки

До замены файлы сохраняются на ПК в `itrampoline-backups/<время>-<id>/`
в папке, из которой вы запустили команду. Исходные игры и избранное не меняются.

Чтобы отменить установку, подключите SD к ПК при выключенном стике:

1. Откройте `restore.json` в папке резервной копии: там указано, какие файлы куда вернуть
   и какие у них были права доступа.
2. Восстановите сохранённые файлы и их права. Файлы с `backup: null` удалите:
   до установки их не было.
3. Безопасно извлеките SD из ПК.

При ошибке или отмене часть файлов может быть уже заменена. Автоматического
восстановления нет; резервные копии остаются на ПК.
