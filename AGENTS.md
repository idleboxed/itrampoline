# Инструкции агента

Используй [IDLE.md](IDLE.md); уточнения проекта имеют приоритет.

## Проект

`itrampoline` — переносимая Python-утилита ПК и тонкий Rust libretro-трамплин:
штатное меню → SD `.so` → exec небольшого helper → exec приложения.
NOR не меняется. BOX2 закрыт; аппаратная история не является проверкой этого проекта.
Текущий профиль — исследованный штатный launcher GBX-066-V02, ARMv7 hard-float.
Не обещай совместимость произвольного GUI, ABI или платы.

Python-код находится в `src/itrampoline/`; тесты сгруппированы по компонентам
непосредственно в `tests/`, без вложенного каталога с именем пакета.
Rust workspace поставляется как ресурс в `src/itrampoline/resources/runtime/`:
`common` — файловые проверки, `core` — libretro ABI, `helper` — операции после exec.
Ресурсы читаются через `importlib.resources`, без соседних проектов и дампов.
Нижние слои не зависят от argparse, input или print.

## Уточнения

- Согласованный CLI: `itrampoline SD_PATH [--no-ask]`. Путь обязателен;
  без флага спрашивается номер платформы и разрешение замены существующих файлов.
  С флагом используются defaults, конфликтующие файлы не заменяются молча.
  Другие команды, аргументы и флаги сначала согласовать с владельцем.
- Трамплин не собирает iman: token задаёт относительный путь приложения,
  по умолчанию `system/iman/iman`. SHA/размер конкретного приложения не закреплять.
- Не переносить UID/NOR/p5/геометрию BOX2 в новый файловый runtime.
  Сохранять удержание FD, NOFOLLOW, regular/single-link/execute и same-device;
  причины проверок описаны в [docs/runtime.md](docs/runtime.md). Писателей SD/NOR здесь нет.
- Не закрывать чужие FD внутри живого RetroArch: очистка только после первого exec.
  Не запускать vendor ELF. Опыты на SD/NOR, GPIO и питании отдельно согласовать;
  sudo выполняет только владелец.
- Локальная установка: `uv tool install --force -e .`; разработка: `ma tools`,
  `ma tests` из каталога пакета, только Python 3.12. Это исключение из IDLE.md.
- Wheel содержит пакет, необходимые исходные Rust-ресурсы, метаданные и лицензию;
  sdist также тесты и документы — исключение из IDLE.md. Cargo.lock поставляется,
  uv.lock, кеши и готовые ARM ELF в исходный пакет не включать.
- Проверки — только офлайн и по изменённым пакетам; линтеры и форматтеры запускать
  только по прямой просьбе. Не выдавать host-тесты и ARM-сборку за аппаратный запуск.
- Размещение пофайловое, DB последняя. Сохранять исходные игры и бэкапы изменяемых
  файлов на ПК, отказывать до записи при неизвестной схеме и подмене путей.
  Не заявлять атомарность всей установки или устойчивость SD к отключению питания.
